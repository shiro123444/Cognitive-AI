## Simulation interface

Existing `neuron_simulator` / `exp-neuron-spike` remains real deterministic LIF with parameters `{stimulus_current:0.5..20, duration_ms:50..500}` and output `membrane_potential:{t_ms,v_mv}`, `spike_times`, `total_spikes`, `firing_rate`, `threshold_mv`, `reset_mv`, `dt_ms`, `duration_ms`. Current gain is arbitrary teaching units, not physical microamps. Do not present LIF threshold crossings as biophysical action-potential shapes.

New HH is a single isopotential squid-axon membrane patch at 6.3 C, classic Hodgkin-Huxley with V=-65mV baseline, C=1uF/cm2, gNa=120/gK=36/gL=0.3mS/cm2, ENa=50/EK=-77/EL=-54.387mV. Gate rates use standard -65mV convention. Solve coupled V,m,h,n ODEs with RK4 dt=0.025ms, analytic limits/expm1 near removable singularities; no reset or artificial spike shape. Explicit square pulse from 10ms until duration-10ms. No claims of NEURON engine, clinical accuracy, full brain simulation or measured human data.

Input HH params accept flat `{stimulus_current:0..30, duration_ms:50..300, g_na_scale:0..1, g_k_scale:0..1}`, defaults10,120,1,1. Validate finite numbers, reject bool, invalid nesting, fractional duration and bounds. May also support normalized `{stimulus:{stimulus_current,duration_ms},channels:{g_na_scale,g_k_scale}}`. Return normalized params in that shape.

HH result data pinned keys: `model:'hodgkin_huxley'`, `duration_ms`, `dt_ms`, `params`, `membrane_potential:{t_ms:number[],v_mv:number[]}`, `spike_times:number[]` (upward crossing 0mV), `total_spikes`, `firing_rate` (spikes / total duration seconds), `threshold_mv:0`, `currents:{i_na:number[],i_k:number[],i_leak:number[],i_stim:number[]}` in uA/cm2, `gating:{m:number[],h:number[],n:number[]}`, `events` with stimulus window, `pipeline_trace`. All sample arrays equal length; finite, bounded <=16001 samples. Include metadata documenting method, constants/temperature/units. `summarize_artifacts` supplies total_spikes,firing_rate,mean_potential,max_potential,threshold_reached,model. Use same real persistent artifact flow as other adapters. Report content must describe this model, not synthetic EEG.

References verified by coordinator: https://models.physiomeproject.org/workspace/hodgkin_huxley_1952/file/2135095d2e2cd9dd671afaea954e523dc0c4d451/hodgkin_huxley_1952.cellml and https://brian2.readthedocs.io/en/2.10.1/examples/IF_curve_Hodgkin_Huxley.html . Note voltage-reference differences in original CellML; use one consistent -65mV convention.
