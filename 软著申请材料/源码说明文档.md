# 1. 前端应用模块

前端位于 `frontend/`，负责课程学习、知识图谱、AI 辅导、NeuroLab、教师工作室、作业和 Runtime 观察界面。

`src/App.vue` 和 `src/router/` 负责应用入口、路由和角色访问控制；`src/views/CourseView.vue` 展示课程章节和学习内容；`src/views/TutorView.vue` 负责 AI 辅导交互与流式结果展示；`src/views/LabView.vue` 实现 NeuroLab 实验工作台；`src/views/TeacherStudioView.vue` 实现教师材料、审核和图谱工作流；`src/views/RuntimeInspectorView.vue` 负责 Runtime 会话、运行和事件观察；`src/components/` 提供图谱、实验画布、脑影像、图表和通用组件；`src/api/` 提供后端与 Runtime 的 HTTP 客户端。

# 2. Python 领域服务模块

后端位于 `backend/app/`，使用 Flask 提供课程、认证、材料、图谱、实验、分析和 Runtime capability API。

`api/courses.py` 提供课程与章节查询接口；`api/runtime_capabilities.py` 是 Node Runtime 调用领域能力的 HTTP 入口；`services/tutor_service.py` 负责课程检索、模型调用和辅导结果组织；`services/runtime_capability_service.py` 负责能力发现、调用与工具事件封装；`services/` 包含材料、图谱、实验、报告和教学分析服务；`agents/` 包含 Agent 工具注册与领域能力定义；`tests/` 包含后端单元和接口测试。

# 3. Agent Runtime 模块

运行时位于 `runtime/`，用于维护 Agent 权威执行状态。它将会话、运行、事件、工具调用和多 Agent 委派拆分为独立模块。

`src/protocol/` 定义版本化协议、命令和事件类型；`src/core/` 实现会话服务、运行状态机、策略、上下文授权和事件总线；`src/persistence/` 实现 PostgreSQL 连接、迁移和 Session/Run/Event 存储；`src/agent/agent-loop.ts` 实现模型调用、工具执行、事件写入和运行结束逻辑；`src/agent/agent-catalog.ts` 定义 Agent 能力白名单和可委派目标限制；`src/agent/openai-provider.ts` 处理 OpenAI-compatible 模型请求与工具名称适配；`src/api/routes/` 提供健康检查、会话、运行、事件轮询和 SSE 路由；`test/` 包含协议、状态机、持久化、HTTP、能力桥接和多 Agent 测试。

# 4. 部署与验证模块

`deploy/docker-compose.yml` 编排前端、领域服务、PostgreSQL 和 Runtime；`deploy/nginx.conf` 提供 `/api`、`/health`、`/runtime` 反向代理；`deploy/verify-runtime-e2e.sh` 用于 Runtime 容器级健康检查和会话/运行验证；根目录 `package.json` 提供覆盖后端、前端和 Runtime 的测试与构建入口。

# 5. 源程序鉴别材料生成方式

执行以下命令：

```bash
bash 软著申请材料/scripts/generate_source_material.sh
```

该命令生成 `软著申请材料/源程序鉴别材料.txt`。材料按模块连续列出前端、后端和 Runtime 的关键源码，并在每个文件前保留相对路径和行号，便于核验。提交前应根据登记机构或学校要求确认页数、页眉、页脚、字号和是否需要截取首尾连续页。
