# 清舟教育智能体平台 V1.0 软著申请材料

本目录按 `/home/shiro/July/软著/软著申请` 中现有模板的章节结构整理，供校内备案和软件著作权登记材料编制使用。

## 文件清单

- `使用说明文档.md`：面向登记材料的功能、运行环境与操作说明。
- `源码说明文档.md`：源程序模块说明、主要目录与验证方式。
- `申请信息核对表.md`：提交前必须逐项核对的权属、版本与联系人信息。
- `scripts/generate_source_material.sh`：从当前已验证源码生成可打印的源程序鉴别材料。

## 使用顺序

1. 先核对 `申请信息核对表.md`，尤其是软件名称、著作权人、完成日期和首次发表信息。
2. 执行 `bash 软著申请材料/scripts/generate_source_material.sh` 生成 `源程序鉴别材料.txt`。
3. 使用 Pandoc 将两份说明文档导出为 DOCX；源程序鉴别材料以等宽字体打印或另行导出为 PDF。
4. 将内容填写进校内备案表和软件著作权登记申请表。原模板只作为格式参考，不覆盖原文件。
